## 🎯 Usage Guide

### Tab 1: Produktsuche
1. Enter product name
2. Click "🔍 Suchen"
3. See results with prices and profit

### Tab 2: AI Hub
1. Select AI Model (Gemini/Copilot/etc)
2. Type prompt
3. Get response
4. Use for dropshipping advice

### Tab 3: Drawing Canvas
1. Select brush/pencil
2. Draw on canvas
3. Click "🤖 AI Generate" to enhance
4. Save drawing

### Tab 4: Website Converter
1. Enter website URL
2. Select conversion options
3. Click "📥 Import"
4. See XAML preview
5. Click "✅ Konvertieren"

### Tab 5: Autonomous Agent
1. Click "▶️ Start"
2. Watch 1000 clones work
3. See revenue generation
4. Monitor logs

### Tab 6: Graphic AI
1. Enter image prompt
2. Select AI model
3. Click generate
4. Use generated image

### Tab 7: Profitrechner
1. Enter supplier price
2. Adjust margin slider
3. Click "📊 Berechnen"
4. See profit calculation

### Tab 8: Bestellungen
1. View all orders
2. See status
3. Track shipments
