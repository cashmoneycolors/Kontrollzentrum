# 🖥️ Amazon Dropshipping Desktop App

**Windows Desktop Application (WPF)** für Amazon Dropshipping Management.

## ✨ Features

- ✅ Produktsuche mit Preisvergleich
- ✅ Automatische Preisberechnung
- ✅ Bestellverwaltung
- ✅ Live-Statistiken
- ✅ Demo-Modus (keine API-Keys nötig)
- ✅ Moderne WPF UI
- ✅ MVVM Architektur

## 🚀 Quick Start

### 1. Voraussetzungen
- Windows 10/11
- .NET 8.0 SDK

### 2. Starten

**Visual Studio:**
- Öffne Projekt
- Drücke `F5`

**Command Line:**
```bash
cd dropshipping_desktop
dotnet run
```

### 3. Verwenden
- Produktsuche durchführen
- Preise berechnen
- Bestellungen verwalten
- Statistiken anschauen

## 📁 Struktur

```
Models/          - Datenmodelle
Services/        - Business Logic
ViewModels/      - MVVM ViewModels
Views/           - WPF UI
```

## 🔧 Technologie

- **Framework:** .NET 8.0 WPF
