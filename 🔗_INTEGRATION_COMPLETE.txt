🌳 GIT WORKFLOW (Git Flow)

Branching Strategy:
  main/          ← Production Releases
  develop/       ← Integration Branch
  feature/*      ← Feature Development
  release/*      ← Release Preparation
  hotfix/*       ← Critical Fixes

Commit Convention:
  feat(scope): description
  fix(scope): description
  docs(scope): description
  test(scope): description
  chore(scope): description

Pull Request Process:
  1. Create feature branch
  2. Develop & test
  3. Push to remote
  4. Create Pull Request
  5. Code review (2+ approvals)
  6. Merge to develop
  7. Delete feature branch

🚀 DEPLOYMENT STRATEGY

Local Development:
  $ git clone --recursive https://github.com/user/kontrollzentrum-master.git
  $ cd kontrollzentrum-master
  $ python setup.py develop
  $ python main.py team

Docker Deployment:
  $ docker build -t kontrollzentrum:5.0 .
  $ docker run -p 8000:8000 -p 8501:8501 kontrollzentrum:5.0

Kubernetes Deployment:
  $ kubectl apply -f kubernetes.yml
