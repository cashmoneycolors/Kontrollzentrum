🛠️ TROUBLESHOOTING
════════════════════════════════════════════════════════════════

API Gateway won't start:
  - Check if port 8000 is free
  - netstat -ano | findstr :8000
  - Kill process: taskkill /PID <PID> /F

Module health check fails:
  - Run: python main.py health
  - Check error messages
  - Review logs in database

Database issues:
  - Reset: rm kontrollzentrum.db
  - Restart API: python main.py api

High CPU/Memory:
  - Check metrics: python main.py health
  - Clear cache: python -c "from core.rate_limiter import cache; cache.clear()"
