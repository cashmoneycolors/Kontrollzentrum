## 🆘 TROUBLESHOOTING

```bash
python -m py_compile modules/*.py
```

### Problem: API nicht erreichbar
```bash
# Lösung: Port prüfen
netstat -an | grep 8000
```

### Problem: Database Fehler
```bash
# Lösung: Database zurücksetzen
rm kontrollzentrum.db
python main.py team
```
